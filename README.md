# Container Navigation System (CNS)

コンテナ荷降ろし作業を支援するWebアプリケーション。
Excelファイルから品目データを読み込み、リアルタイムの作業追跡・音声認識・読み上げ機能を提供する。　

## 主な機能

### 作業モード
- 品目の大型表示（品名・種類・色バッジ・パレット図）
- **端数パレットの全画面表示**: 残りが端数パレットだけになったとき、または端数パレットの図をタップしたときに、
  画面に出ているパレットの位置から
  全画面へ1.4秒かけてゆっくり移動し、積み方を見せる。背景は明るさを変えずガウスぼかし（`blur(18px)`）だけを掛ける。
  移動中も回り続けるので、回転しながら手前に出てきて回転しながら元の位置へ戻る
  （全画面表示のパレット図は出現フェード `palletFadeUp` を省き、動き出しから見えるようにしている）。
  下部には作業画面の CT / pcs 表示（数値 + 端数 + CT、総数 + pcs）をそのままの内容で大きく表示し、
  文字も CT・pcs 表示を囲む範囲の位置・大きさから図と一緒に下りてくる（数値は表示中のカウント値をそのまま使う）。
  横スワイプで回転（画面幅いっぱいのスワイプで180度）。無操作時の自動回転は 260度/秒 で始まり、
  作業画面の端数パレットと同じ速さ（15秒で1回転 = 24度/秒）へ徐々に落ちていく（時定数1.8秒）ので、
  元に戻ったときに回転の速さが揃う。7秒の表示中におよそ1.5周する。
  回転角は state ではなく ref で持ち、毎フレーム DOM の transform を直接書き換える
  （React の再描画を挟むと 20fps 程度に落ちてカクつくため）。
  表示は7秒で、触ると最後の操作から数え直す。図の外をタップするとすぐ戻る。
  実装は `src/components/ItemDetailPanel.tsx`。
- アイソメトリック3Dパレット図（汎用5+4配置 / ジャーポット互い違い配置）
- パレット枚数・端数ケース・総数のリアルタイム表示
- スワイプ操作（左→完了、右→取り消し）
- 類似品目の警告表示（色違い・1文字違い）

### 音声制御
- 日本語音声認識（Web Speech API）
- 音声コマンド: 次/前/完了/読み上げ/増減/数量確認/残数確認
- 品目切り替え時の自動読み上げ（ON/OFF切替可能）
- 品目ごとの完了コールは行わない（作業テンポ優先）。全品目完了時のみ「全品目の荷降ろしが完了しました」とコールする
- 類似品がある品目では「類似品があります」とだけコールする（色違い・品名違いの具体的な内容や数量は読み上げない）

#### コールする内容（必要最低限にする方針）
現場で必要な情報だけをコールし、それ以外は画面表示にまかせる。

- **コンテナ読み込み時のコールなし**: 「荷降ろしを開始します」も、種類ごとの内容案内（「◯◯が N 種類」）も読み上げない。
  読み込み後は最初の品目コールだけが鳴る（`src/app/page.tsx` の読み込みエフェクト）。
  メニューの概要コールを押したときは「残り◯品」＋類似品の注意だけを伝える（`announceContainerSummary`）。
- **品名は画面の表示名だけ**: 部品は画面に出ている日本語名だけをコールし、「／」より後ろの詳しい型式までは読まない
  （`itemNameForCall` — `src/lib/partTranslations.ts`）。
- **数量は画面の PL / CT と同じ値**: ポリカバーなど検査で1ケース抜く品目は、抜いた後の数をコールする。
  品目コール・OKコール・残数コールのすべてで `displayQuantities` / `quantitiesAfterPalletRemoved`
  （`src/lib/itemQuantity.ts`）を使い、画面と音声の数字が食い違わないようにしている。
- **パレット数を戻したときはコールしない**: 増やす操作（＋ / 「戻して」）は画面表示のみ。
- **10分ごとのコールは「◯分経過しました」だけ**: 気温・湿度は既定でコールしない。
  設定 →「音声・コール」→「コールの内容」の「10分ごとのコールで気温・湿度も伝える」をオンにしたときだけ付く（`cns_call_10min_climate`）。
- **気温・天気コールにアドバイスを付けない**: 気温・湿度・暑さ指数と警戒レベルの数値だけをコールする。

#### 音声（TTS）の設定
メニュー →「設定」→「音声」で、コールに使う音声をまとめて設定する。設定は localStorage（`cns_voice_settings`）に保存。

- **音声 API**: `Gemini TTS`（高品質・要 API キー・通信あり）／`sherpa-onnx`（端末内で高音質・通信なし）／
  `端末の音声`（Web Speech API・準備不要）。Gemini を選んでいてもキー未設定なら端末の音声で鳴らす。
- **API キー / モデル**: キーは AI写真の設定と共通（`cns_gemini_key`）。TTS モデル名も変更できる。
  キー欄の横には Google AI Studio のキー取得ページ（`https://aistudio.google.com/app/apikey`）を別タブで開くボタンを置いている（AI写真の設定も同じ）。
- **プロファイル**: 「通常コール」と「応援コール」で、話す人（10種）・トーン・速さ・高さを別々に設定できる。
  トーンはプリセット（はっきり／穏やか／明るい／応援／急かす／低め）か自由記述。
  速さ・高さは Web Speech では数値でそのまま、Gemini では指示文（「ゆっくりと」「低めの声で」等）に変換して渡す。
- **音量**: 0〜300%。100% が端末の音量そのままで、それを超える分は Web Audio のゲインで増幅する
  （`src/lib/audioBoost.ts`）。荷降ろし現場の騒音でコールが小さいときに使う。
  増幅の前にコンプレッサーを通し、語尾など小さい部分を持ち上げてから上げるので歪みにくい。
  端末の音声（Web Speech API）は再生される音を取り出せないため、`SpeechSynthesisUtterance.volume` の
  上限 1.0 = 100% が上限になる（設定画面にもその旨を出す）。大きくしたいときは Gemini TTS に切り替えるか、
  端末側のメディア音量を上げる。試聴ボタンで実際の声と音量を確認できる。
- 実装: `src/lib/voiceSettings.ts`（設定）、`src/components/VoiceSettingsPanel.tsx`（UI）、
  `src/lib/geminiTts.ts`（Gemini TTS クライアント）、`src/lib/sherpaTts.ts`（sherpa-onnx クライアント）、
  `src/lib/ttsAudio.ts`（WAV 組み立て・日本語の前処理）、`src/lib/audioBoost.ts`（音量ブースト）、
  `src/hooks/useSpeech.ts`（コール生成）。

#### sherpa-onnx（端末内 TTS）
Next-gen Kaldi の [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)（Apache-2.0）を WebAssembly で動かし、
通信なしでコールする。VITS / Piper / Kokoro などの軽量・高音質モデルを ONNX のまま読み上げるので、
端末標準の音声より抑揚が自然で、Gemini TTS のような生成待ちも通信も要らない。

- **必要なファイル**: sherpa-onnx の wasm/tts ビルド一式（`sherpa-onnx-wasm-main-tts.js` / `.wasm` / `.data`、
  `sherpa-onnx-tts.js`）を `public/sherpa/` に置く。置き場所は設定ページの「モデルの置き場所」で変更でき、
  別ホスト（CORS 許可が必要）も指定できる。作り方は `public/sherpa/README.md`。
- **読み込みとキャッシュ**: `.wasm` / `.data` は進捗を出しながら取得し、Cache Storage（`sherpa-onnx-tts-v1`）に残す。
  2回目以降は圏外でも立ち上がる。取得済みバイナリは Emscripten の `wasmBinary` / `getPreloadedPackage` に直接渡すので、
  同じファイルを二重に取りに行かない。設定ページの「保存分を削除」で消せる。
- **話者と速さ**: 複数話者モデルは「話者番号」（`sid`）で選ぶ。話す速さはプロファイルの `rate` を
  sherpa-onnx の `speed` にそのまま渡す（トーン指示文は Gemini TTS 専用）。
- **フォールバック**: モデルが未配置・読み込み失敗のときはコールが無音にならないよう、その場で端末の音声に切り替える。
- **先読み**: 設定の「アプリを開いたら先に読み込む」がオンなら起動時に読み込んでおく（既定オン）。

#### 気温・暑さ指数のコール
天気コール（🌦ボタン / 「天気」）・気温コール（「気温」）では、
気温・湿度・暑さ指数（WBGT）と警戒レベル（危険／厳重警戒／警戒／注意／ほぼ安全）を読み上げる。
10分ごとの定期コールでは既定で読み上げない（設定でオンにしたときだけ付く）。

- **SwitchBot 接続中は実測値を優先**: SwitchBot 温湿度計をスキャン中で、かつ最終受信から10分以内なら、
  気象庁データではなく実測の気温・湿度・WBGT でコールする（それ以外は気象庁データ）。
  10分ごとの定期コールで気温・湿度をオンにしている場合は、実測値があるときは気象庁データの取得を待たずに実測値をコールし、
  コールした数値がそのまま見えるよう SwitchBot のポップアップを開く（気象庁データはバー表示だけ裏で更新）。
- **アドバイスは付けない**: 「水分補給をしてください」等の注意喚起はコールしない（数値と警戒レベルのみ）。
- **天気コールは予報も読む**: 現在値に続けて、その日の最高気温と1日を通した降水確率（`precipitation_probability_max`）をコールする。
- **10分ごとの定期コールの数え方**: `setInterval` ではなく作業の経過時間（`useWorkTimer` の秒数）が10分をまたぐたびにコールする。
  一時停止中は経過時間が進まないため、止めている間はコールもされず、止めた時間ぶんコールがずれることもない。
- 実装: `src/lib/weatherNews.ts` の `climateToSpeech` / `forecastToSpeech`。

### 経過時間の一時停止
休憩に入るときに、作業の経過時間をその場で止められる。ヘッダー中央の経過時間をタップ →「一時停止」。

- **止まるもの**: 経過時間と品目ごとの時間、10分ごとの定期コール、品目切替の自動コール、
  いま鳴っている音声コール（`cancelSpeech`）、水の音BGM、せせらぎモードの映像と川の音。
- **再開**: 止めていた時間ぶんだけ `workStartTime` / `itemStartTime` をうしろへずらすので、
  休憩時間は経過時間に入らない。水の音は「一時停止で止めたときだけ」元に戻す。
- **表示**: ヘッダーの経過時間が薄い色に変わり、下に「一時停止中」と出る。
  せせらぎモード中は右上の経過時間をタップして止め／再開でき、止めている間は画面中央に「一時停止中 — タップで再開」を出す。
- 実装: `src/hooks/useContainerData.ts`（`workPausedAt` と `PAUSE_WORK` / `RESUME_WORK`）、
  `src/hooks/useTimer.ts`（`useWorkTimer(startTime, pausedAt)`）、`src/app/page.tsx`（`toggleWorkPause`）、
  `src/components/HeaderBar.tsx` / `src/components/RiverMode.tsx`（UI）。

### 作業用BGM（水の流れる音）
作業中に流す水音。右下のクイックメニュー →「水の音を流す／止める」で再生・停止、同じ行の歯車またはメニュー →「設定」→「水の音」で設定を開く。

- **音源**: 実録音の水の流れる音。30秒のシームレスループ素材（`public/sounds/water-loop.mp3` / MP3 128kbps モノラル・約470KB）。
  末尾2秒を先頭へ等パワークロスフェードして作成しているため、継ぎ目でクリックノイズが出ない。
- **フェードイン・アウト**: 再生開始と停止はS字カーブ（ease-in-out）でなめらかに出入りする。フェード時間は 0.5〜12秒で調整可能。
- **自動ダッキング**: 音声コール中は BGM の音量を自動で下げ、コール終了後に戻す
- **自動再開**: 「次回起動時も自動で流す」をオンにすると、次回起動後の最初の操作で再生を再開する（ブラウザの自動再生制限に対応）
- **ループ位置**: 再生のたびにループ区間内のランダムな位置から鳴らすため、毎回同じ出だしにならない
- 実装: `src/lib/waterSound.ts`（再生エンジン）、`src/hooks/useWaterSound.ts`、`src/components/WaterSoundPanel.tsx`（設定ページの「水の音」タブ）
- 設定は localStorage に保存（`cns_water_volume` / `cns_water_fade` / `cns_water_playing` / `cns_water_autostart`）
- 停止後は AudioContext を休止してバッテリーを節約する
- 注意: iPhone はマナーモードでは音が鳴らない

### せせらぎモード（川の映像）
右下のクイックメニュー →「せせらぎモード」で、川のループ動画を全画面に出す休憩用の表示。
水の音（BGM）が止まっていれば一緒に流し始め、戻るときはこのモードで流し始めた場合だけ止める。

- **縦向きの高画質素材**: 元動画は 1080×1920 / 30fps / 10秒。スマホを縦に持ったときに全画面へぴったり収まる。
- **継ぎ目のないループ**: 元動画から、先頭と末尾が最も近くなる区間（開始 0.40 秒・長さ 8.37 秒）を総当たりで選び、
  その続きの 1.2 秒を先頭にクロスフェードして 8.37 秒のループに作り直している（`public/videos/river-loop.mp4`）。
  ループのつなぎ目の絵の差（MSE 31.0）は、通常のコマ送り1コマ分（中央値 25.1・最大 58.5）の範囲に収まっているので、
  何周しても切り替わりが分からない。
- **形式**: H.264 の MP4（1080×1920 / CRF 23 / 約 5.7MB）と VP9 の WebM（720×1280・約 2.9MB）を用意し、
  `<source>` で MP4 を優先。音声は入れていない（BGM は水の音の機能を使う）。
  読み込み前は 1 コマ目のポスター画像（`river-poster.jpg`）を出す。
  `muted` + `playsInline` + `autoPlay` で iOS でもそのまま再生できる。
  動画はせせらぎモードを開いたときだけ読み込むので、通常の起動時には転送されない。
- **タップ**: **画面の下 1/3 をタップすると元の画面に戻る**（Esc でも戻れる）。上 2/3 は波紋 + 品目情報の表示。
- **川から浮かび上がる品目情報**: 上 2/3 をタップすると、いま作業中の機種名（代表機種）と PL / CT / pcs が
  川面から浮かび上がり、9秒たつとまた沈む。もう一度タップすると表示時間を数え直す。
  - 文字は「石に苔が生えた」見た目。灰白色の石のグラデーションに緑の斑点を重ね、`background-clip: text` で文字型に切り抜いている。
    影は `text-shadow` だと切り抜いた背景の上に乗ってしまうため `filter: drop-shadow()` で付け、輪郭は `-webkit-text-stroke` で彫り込む。
  - 出現は下からせり上がりながらぼかしが取れる動き（`river-surface`）、消えるときはその逆（`river-sink`）。
    文字の後ろの水面は放射状の暗幕で少し翳らせて読みやすくしている。
  - **パレット数（PL）はタップで1枚減らせる**。作業画面と同じ `handleDecrease` を呼ぶので、
    残り0枚のときは品目が完了になり次の品目へ進む。PL / CT / pcs の計算も作業画面と共通（`src/lib/itemQuantity.ts`）。
- 表示中は Wake Lock で画面を消灯させない。バックグラウンドから戻ったときは再生を再開する。
- 実装は `src/components/RiverMode.tsx`。

### 気温表示（ヘッダー右）
ヘッダーは1行だけで、右端に気温・湿度・暑さ指数を出す（旧・温湿度バーは廃止）。
- 気温は「数値 + 温度計アイコン」、湿度は「数値 + しずくアイコン」の順（アイコンは数値の右側）。暑さ指数は WBGT のレベルで色が変わるバッジ
  （ほぼ安全=緑／注意=黄／警戒=橙／厳重警戒=濃橙／危険=赤）。
- SwitchBot 受信中は実測値を表示する。ヘッダーには出所の「S」マークも気象庁との差分も出さず、数値だけを見せる
  （差分はポップアップ側で確認する）。
- タップで詳細（SwitchBot 受信中は SwitchBot ポップアップ、それ以外は気象庁の推移グラフ）を開く。
  出典（気象庁）と観測時刻はポップアップ側に表示する。
- **気象庁データ**: Open-Meteo から現在地（鳥取市気高町宝木）の気温・湿度を取得し、WBGT を推定表示。10分ごとに自動更新。
  表示・読み上げ上の地名は「鳥取市」に統一している。
- **SwitchBot 温湿度計（Bluetooth）**: 「接続」ボタンで SwitchBot 温湿度計の BLE アドバタイズをスキャンし、実測の気温・湿度・WBGT を表示。
  - **ポップアップは SwitchBot のロゴに合わせた赤** (`#d13938`)。白の「S」マーク＋半透明の白いカードで、
    数値・目盛り・凡例は赤地で読めるように、気温=明るい黄 `#ffd166` / 湿度=明るい水色 `#a5e8ff` / 暑さ指数=白の破線に振っている。
    警戒レベルのバッジは、赤地に沈まないよう白地＋レベル色の文字にした。
  - 気象庁の予報値との差分（SwitchBot − 気象庁）は、ヘッダーではなくこのポップアップ内に表示する。
  - 仕組み: Web Bluetooth の `navigator.bluetooth.requestLEScan`（ペアリング不要・受信のたびに最新値へ更新）。
  - 対応: Android Chrome で `chrome://flags/#enable-experimental-web-platform-features` を有効にすると利用可能。非対応環境ではバーに「非対応」と表示される。
  - 接続・停止は右下のクイックメニューから行う（状態と対処法は同じ行の「i」で確認できる）。
  - 実装: `src/lib/switchbot.ts`（SwitchBot Meter サービスデータ解析）、`src/components/HeaderBar.tsx`（ヘッダー右の表示）、`src/components/QuickActions.tsx`（接続操作）。

### ヘッダー・メニュー・読込画面（UI）
- **ヘッダーは常に固定**: `html, body` 自体をスクロールさせない構成（`overflow: hidden` に加えて `body { position: fixed; inset: 0 }`）にし、
  各ページは内側のコンテナだけがスクロールする。`.app-layout` の高さは `100vh → 100svh → 100dvh` の順に上書きして
  表示領域より高くならないようにし、ヘッダーは `position: sticky` も併用している。
  さらに画面切り替え時に `window.scrollTo(0, 0)` で先頭へ戻すので、作業ページへ移動したときにヘッダーが上に隠れることはない。
- **スマホの横画面はサポートしない**: manifest の `orientation: portrait` と `screen.orientation.lock('portrait')` で
  インストール済み PWA は縦に固定する。ブラウザ表示では向きを固定できないので、
  `(orientation: landscape) and (max-height: 520px)`（＝スマホの横画面）のときだけ
  「画面を縦にしてください」を全画面でかぶせる（`OrientationGuard`）。
  タブレット・PC の横画面は今までどおり2ペイン表示のまま。
- **ヘッダーを下にスワイプして再読み込み**: `body` を固定しているのでブラウザ標準の
  引っぱって更新が効かない。代わりにヘッダー上の下スワイプを自前で拾う（`HeaderBar`）。
  指の移動量に 0.55 を掛けて減衰させ、72px を超えたところで矢印が反転して橙色になり、
  離すと `location.reload()`。8px 以下の動きはタップとして扱うので、メニューなどのボタンは今までどおり押せる。
  スワイプしたときはその直後のクリックを `onClickCapture` で1回だけ飲み込む。
  コンテナ読み込み済みのときは、作業内容が消えるため確認ダイアログをはさむ。
- **ヘッダーは1行・3分割**: `grid-template-columns: 1fr auto 1fr` で、左=メニュー / 中央=経過時間 / 右=気温。
  中央カラムが常に画面中央に来るので、左右の幅が違っても経過時間は真ん中に揃う。高さ 72px（`calc(72px + var(--safe-top))`）。
  経過時間はタップで品目別の作業時間・リセットのポップアップを開く。
  現在時刻は端末のステータスバーに出るため表示しない。狭い画面（≤400px）では文字とバッジを少し詰めて重なりを防ぐ。
- **操作は右下のクイックメニューに集約**: 上向きの山（シェブロン）だけを描いたアイコン（`QuickMenuIcon`）を押すと下から展開し、
  コンテナ選択・応援コール・天気コール・水の音・せせらぎモード・SwitchBot 接続をまとめて操作できる（`src/components/QuickActions.tsx`）。
  ボタンは 48px の角丸タイルで、矢印のまわりに枠線は描かない。開くとアイコンが 180 度回って下向きになる。
  水の音の再生中は右下ボタンが水色に光る。
- **アイコンは白線に統一**: 絵文字（📣 / 💧 / 📡 など）をやめ、`src/components/AppIcons.tsx` の
  `currentColor` ストロークアイコンに統一。ボタンの状態色（水の音 ON の水色など）はそのまま効く。
  例外は Google ドライブボタンで、識別しやすさを優先して公式のカラーロゴを使う。
- **フォントは端末の UI に統一**: `--font-ui`（`-apple-system` / `Hiragino Sans` / `Noto Sans JP` / `Segoe UI` …）を
  `--font-display` / `--font-body` / `--font-mono` と Tailwind の `font-sans` すべてに割り当て、
  画面ごとの書体差をなくした。数字は `font-variant-numeric: tabular-nums` で桁を揃える。
  Web フォントは経過時間用の `Orbitron`（`--font-clock`）だけを読み込む。
- **メニューは画面左側全域**: 上端から下端まで（幅 `min(320px, 82vw)`）を占め、オーバーレイとパネルがフェードインしたあと、
  中身が上から順に 40ms ずつラグを付けて左からスライドしてくる（`globals.css` の `menu-item-in` と `nth-child` の遅延）。
  展開中はマイク（音声）ボタンと右下のクイックメニューを隠す。
  下部のバージョン表示はカードではなく、上に区切り線を引いた1行（`CNS  Ver.7.1 … 2026.8.19 09:32`）として固定する。
  スライドインのアニメーションからも外しているので、メニューを開いた瞬間から動かずそこにある（更新内容の一覧表示は行わない）。
- **読込画面はドロップゾーンと Google ドライブのみ**: GitHub・履歴・AI写真・バージョンのボタンは廃止。
  Google ドライブはドロップゾーンと同じ横幅の大ボタンで、アイコンは Google ドライブ公式ロゴ（カラー）を使う。
  ファイル種別のバッジ表示も廃止した。
- **設定ページ**: メニュー →「設定」で `SettingsPage` を開き、「音声」「コール」「水の音」「AI写真」をタブで切り替える。
- **履歴**: メニュー →「履歴」で `HistoryModal` を開き、「最近のファイル」（再読込）と「更新履歴」をタブで切り替える。
  コンテナ未読込でも開けるので、読込画面からでも過去のファイルを呼び出せる。

### 品目マスタ管理（CNS品目一覧）
CNS品目一覧はコード紐付・入数・1P数・重量・寸法情報を保管するマスタデータ。
パレット枚数・端数は「内容」シート（コンテナデータ）から取得する。

- **新規登録**: 全フィールド入力可能な登録フォーム
- **編集**: 品番・品名・Description・数量・重量・寸法 全項目編集可能
- **削除**: 確認ダイアログ付き
- **CN優先ソート**: 読み込んだコンテナの対象品目を自動的に一覧上部に表示
- 種類フィルター / テキスト検索
- Excel Import（新建高コード一括更新）
- Excel Export（マスタデータ出力 — palletCount/fractionは含まない）

### 写真読込（AI/OCR）
コンテナ日程の書式の写真（JPG/PNG等）をドラッグ＆ドロップすると、
画像から自動で品目表を抽出してコンテナデータとして取り込む。

- 対応フォーマット: `.jpg` / `.jpeg` / `.png` / `.webp` / `.heic` / `.bmp`
- 抽出列: 品番 / 品名 / 代表機種 / 入荷数量 / ケース数 / パレット枚数 / 端数
- ヘッダー左上の「4月15日 26K0308」形式から日付・コンテナ番号を抽出

#### 抽出エンジン
1. **Gemini API (推奨)** — メニュー →「設定」→「AI写真」から Google AI Studio で取得した API キーを設定すると、
   （キー欄の横の「AI Studio でキーを取得」ボタンから取得ページを直接開ける）Gemini 3.6 Flash / 3.5 Flash-Lite / 3.1 Pro を用いて高精度な構造化抽出を行う。光沢・影・日本語英数混在もLLMの文脈理解で高精度に処理。Flash 系モデルは無料枠あり。
2. **Tesseract.js (フォールバック)** — API キー未設定時は tesseract.js のローカル OCR を使用。精度は低いが完全オフライン動作。

API キーは端末の localStorage にのみ保存され、外部には送信されない。

| H | ケース数 (caseCount) | カートン数 |
| I | パレット枚数 (palletCount) | パレット数 |
| J | 端数 (fraction) | 端数ケース |
| K | 1P数 (qtyPerPallet) | 1パレットあたりケース数 |

コード紐付・重量・寸法等の参照情報を保管。

| 列 | フィールド | 説明 |

| B | 気高コード (partNumber) | 品番 |
| C | 規格 (itemName) | 製品名 |
| D | 種類 (type) | ポリカバー/箱/部品/その他（自動判定） |

## 画面モード

すべての画面はヘッダー左のメニューから相互に行き来できる（読込画面もヘッダー・メニューを保持する）。
コンテナ未読込のときは読込画面に固定され、他のメニュー項目は選べない。

| モード | 説明 |
|---|---|
| **読込** (load) | Excel/写真の読込画面。作業中でもメニューから開けて、別ファイルへ差し替えできる |
| **作業** (work) | 品目詳細表示 + パレット図 + 操作バー。横画面では左右分割。全品目完了時は完了表示 |
| **一覧** (list) | 全品目のリスト表示 |
| **管理** (edit) | 品目マスタの登録・編集・削除・Import/Export |
| **分析** (analytics) | コンテナの内容分析 |

メニューからは他に、ページではなくポップアップとして「マニュアル」「設定」「履歴」を開ける。
メニュー下部には区切り線の下に「CNS  Ver.7.1  2026.8.19 09:32」の形でバージョンと最終ビルド日時を表示する。
時刻だけではいつ更新されたものか分からないため、日付も併記する（`src/lib/appVersion.ts` の `APP_UPDATED`。
ビルド時に `next.config.mjs` が日本時間で埋め込む）。

## データフロー

```
Excel (.xlsx) → parseExcelFile() → useContainerData (reducer)
                                        ↓
                              ┌─────────┼─────────┐
                              ↓         ↓         ↓
                        作業ビュー   一覧ビュー  管理ビュー
                              ↓                    ↓
                        音声認識/TTS         Import/Export
```

1. ユーザーがExcelファイルをD&Dまたは選択
2. `parseExcelFile()` が「内容」シートを解析、コンテナ/品目データを生成
3. 同一品番・品名の品目を合算、種類別にソート
4. `useContainerData` のreducerで全状態を管理
5. 音声認識でハンズフリー操作、自動読み上げで作業支援

## 品目種類の自動判定

| 種類 | 判定ルール | 色 |
|---|---|---|
| ポリカバー | 名前に「ポリカバー」を含む / JRI-, JPI- 等の接頭辞 | 緑 |
| 箱 | PDRS, PDU+, PVW- 等の接頭辞 / 「ハコ」「箱」キーワード | 青 |
| 部品 | 「レバー」「パッキン」「スイッチ」等のキーワード | 紫 |
| その他 | 上記に該当しない品目 | グレー |

## PWA / 画面表示

- **表示モード**: `standalone`（`public/manifest.json`、`display_override` にも明示）。`fullscreen` だとスマートフォンのステータスバー（時計・電池）が隠れてしまうため使わない。
  Android はインストール時の表示モードが WebAPK にキャッシュされるため、`fullscreen` で追加済みの端末は
  ホーム画面のアプリを一度削除して入れ直さないと反映されない。
- **テーマカラー**: ステータスバーの色をヘッダー（`--header-bg` = `#1a1d2e`）と同色にして一体感を出す。
  `manifest.json` の `theme_color` / `background_color` と `layout.tsx` の `viewport.themeColor` を同じ値にそろえること。
- **セーフエリア**: iOS はステータスバーが黒半透明（`statusBarStyle: black-translucent`）でコンテンツに重なるため、
  ヘッダーに `env(safe-area-inset-top)`（CSS変数 `--safe-top`）分の余白を持たせ、その領域もヘッダー色で塗る。
  ヘッダー高さは `calc(72px + var(--safe-top))`、メニューパネルは画面左側全域（`top: 0` / `bottom: 0`）を占め、
  内側の上余白を `calc(var(--safe-top) + 12px)` にしてステータスバーを避ける。

## レスポンシブ対応

- **縦画面 (Portrait)**: 詳細パネルのフルスクリーン表示 + 下部操作バー
- **横画面 (Landscape)**: 左50%詳細 + 右50%品目リスト
- **モバイル (≤480px)**: コンパクトグリッド・フォントサイズ調整
- **デスクトップ (≥1024px)**: ワイドグリッド・余裕のある配置
